# Zynvero marketing website

Static GitHub Pages website for Zynvero — AI-powered CRM and customer engagement.

## Structure
- `index.html`: accessible landing page
- `assets/styles.css`: responsive styles
- `assets/main.js`: navigation behavior
- `assets/logo-mark.svg`: original editable vector logo concept
- `assets/favicon.svg`: scalable brand icon

## Publish
In GitHub repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**. The expected project URL is https://aliasgermodi.github.io/zynvero_crm/ after Pages finishes deploying.

## Important
This is a **marketing site**, not the CRM backend. Dashboard numbers are illustrative. The demo mailbox hello@zynvero.com is a placeholder that must be verified or replaced before accepting enquiries. No customer information is collected by this site. Integrations and feature availability depend on the product deployment.

Brand/domain/trademark clearance is still required before adopting a custom domain.
